Este projeto usei para melhorar e por a prova meu conhecimento com JDBC,
integrando diretamente o MySQL ao meu projeto java.

OBS:
pode ser que na data que você esteja vendo este arquivo eu atualizei ou não,
para uma versao mais limpa e com explicações dentro do proprio codigo.

Neste projeto, trabalhei com dua tabelas de um mesmo DATABASE, a tabela de 'estoque'
e tambem tabela de 'vendas'. 
 Em 'estoque' controla todos os produtos, como, nome, preço e quantidade sem produtos cadastrados, nao havera nenhuma interação
com a tabela de vendas. Na tabela de vendas é salvo todas as operações de vendas feitas, salvando as informações:
Nome do produto, preço vendido, a quantidade e o total do valor de acordo com a função: preco * quantidade.

Usei todo meu conhecimento até o momento para minimizar os erros, bugs, e possiveis ocasiões indesejadas no codigo.
